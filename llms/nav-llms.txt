# Nav

> Nav Technologies, Inc. is a US financial-technology company (not a bank) that gives small business owners one place to see their business and personal credit, cash-flow health and funding eligibility, then matches them to a marketplace of financing and business credit card offers. Its developer surface is the partner-gated Nav Partner API (REST, api.nav.com) plus an embeddable widget SDK that renders Nav business-credit UI inside a partner's own application.

This file is GENERATED by API Evangelist from Nav's public documentation and this repository's artifacts. Nav does not publish an llms.txt of its own (probed 2026-08-26: /llms.txt returns 404 on api.nav.com, api.sandbox.nav.com, www.nav.com, api-docs.nav.com and developer.nav.com).

Access model: there is no self-serve developer signup. API keys are issued by a Nav account manager during partner onboarding, and widget-bearing origins must be registered with Nav before production.

## APIs

- [Nav Partner API](https://api-docs.nav.com/docs/rest-api/partner-api): Nine REST operations under https://api.nav.com/v1 — create a Nav account, read it, change its plan, end the partner relationship, resolve bureau credit visibility, manage the widget origin allow list, and mint single-use SSO tokens and login URLs.
- Base URLs: production https://api.nav.com — sandbox https://api.sandbox.nav.com

## Operations

- POST /v1/accounts — Create Account (supports Idempotency-Key, 24h window)
- GET /v1/accounts/{accountId} — Get Account
- DELETE /v1/accounts/{accountId} — End Partner Relationship (idempotent; requires an EndedReason)
- PUT /v1/accounts/{accountId}/plan — Change Plan
- POST /v1/accounts/{accountId}/credit-visibility — Resolve Credit Visibility (auto-confirms bureau matches; not reversible)
- GET /v1/origins — Get Origin Allow List
- PUT /v1/origins — Replace Origin Allow List
- POST /v1/sso-login-url — Create SSO Login URL (single use, 2 minute expiry)
- POST /v1/sso-token — Create SSO Token (single use, 2 minute expiry)
